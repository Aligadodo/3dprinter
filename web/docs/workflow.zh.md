# 工作流系统指南

## 概述

工作流系统允许你将多个流水线阶段串联成一个 **有向无环图（DAG）**，实现端到端的自动化处理。每个节点代表一个处理步骤，节点之间通过连接线传递文件路径。

典型工作流示例：`文字 → 图片 → 浮雕 → 网格修复 → 输出`

## 节点类型

系统提供 **20 种节点类型**，分为 4 个类别：

### 输入类（Input）

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| File Input | — | file | 上传文件作为工作流输入 |
| Text Input | — | text | 文本输入（如提示词），可为下游节点提供 prompt |

### 生成类（Generate）

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| Text → Image | prompt, size, provider | image | 调用 AI API 生成图片，支持 4 供应商 |

### 处理类（Process）

#### 图片→3D

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 浮雕 Relief | image | stl, color_preview | CPU 任务，图片转浮雕 |
| 夜灯 Lithophane | image | stl, color_preview | CPU 任务，图片转夜灯 |
| 套色浮雕 Layered | image | stl, 3mf, color_map, color_preview | CPU 任务，多色浮雕 |
| TripoSR 快速3D | image | mesh, preview | GPU 任务，快速 AI 建模 |
| Hunyuan3D 高质量 | image | mesh, preview | GPU 任务，高质量 AI 建模 |

#### 网格处理

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 六视图 Views | mesh | grid, views_dir | CPU 任务，渲染六视图 |
| 网格修复 Repair | mesh | repaired_mesh | CPU 任务，修复封闭网格 |
| 网格简化 Simplify | mesh | mesh | CPU 任务，减面降低文件大小 |
| 网格平滑 Smooth | mesh | mesh | CPU 任务，Taubin 平滑去噪 |
| 网格缩放 Scale | mesh | mesh | CPU 任务，按比例或目标尺寸缩放 |

#### 图像处理（内联 PIL 节点，不走子进程）

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 图像缩放 Resize | image | image | 调整尺寸，支持 5 种适配模式 |
| 灰度转换 Grayscale | image | image | 彩色转灰度，支持 6 种算法 |
| 图像裁切 Crop | image | image | 裁切图像，支持预设宽高比 |
| 图像调节 Adjust | image | image | 亮度/对比度/饱和度/锐度调节 |
| 格式转换 Convert | image | image | 转换图像格式（PNG/JPEG/WebP 等） |
| AI 去背景 Remove BG | image | image, mask | AI 模型去除背景，可选替换背景色 |

### 输出类（Output）

| 节点 | 输入 | 输出 | 说明 |
|------|------|------|------|
| Output | file | — | 标记工作流输出文件（可下载为 ZIP） |

## 编辑器使用

### 打开编辑器

导航到「工作流编辑器」页面，或从工作流列表中选择一个已有工作流。

### 添加节点

节点面板按类别分组显示，从左侧拖拽到画布上：
- **输入**：File Input、Text Input
- **生成**：Text → Image
- **处理**：浮雕、夜灯、套色浮雕、TripoSR、Hunyuan3D、六视图、修复、简化、平滑、缩放、缩放、灰度、裁切、调节、转换、去背景
- **输出**：Output

### 连接节点

从一个节点的**输出端口**（右侧圆点）拖拽连线到另一个节点的**输入端口**（左侧圆点）。连接线表示数据流向。

### 配置参数

点击节点可查看和修改其参数。每个节点都有默认参数值，可根据需要调整。节点参数均为中英双语标注。

### 内置模板

编辑器提供 4 个预置模板：

1. **基础流程**：`文本→图→浮雕` — 最简单的文生 3D 流程
2. **进阶流程**：`文本→图→套色浮雕→修复` — 带多色和修复的完整流程
3. **完整流程**：`文本→图→3D→六视图` — 含 AI 高质量建模和六视图输出
4. **图像处理**：`文件输入→缩放→去背景→格式转换` — 纯图像处理链

## 执行流程

1. 点击 **保存** 按钮保存工作流定义
2. 点击 **运行** 按钮 → 弹出参数对话框（可选配置输入值）
3. 系统创建新的工作流实例
4. 引擎对 DAG 进行拓扑排序（Kahn 算法），确定执行顺序
5. 并行分支可同时执行，串行依赖按序等待
6. 每个节点执行时，前端 Runner 页面实时显示进度：
   - 左侧：节点 Tab 切换（点击查看不同节点的输出）
   - 中部：节点详情面板（输入/输出文件、参数、日志）
   - 右侧/顶部：DAG 实时状态图
7. 全部完成后显示结果，可下载 ZIP 包

## 运行器界面 (Runner)

Runner 页面采用分区布局：

```
┌──────────┬──────────────────────────────────┐
│ 节点Tab  │  DAG 实时状态图                    │
│ ─────── │  (灰色=等待 / 蓝色=运行 /          │
│ ✓浮雕     │   绿色=完成 / 红色=失败)           │
│ ▶修复     │                                  │
│   视图    ├──────────────────────────────────┤
│          │  节点详情面板                       │
│          │  输出文件预览（图片/STL/3D）       │
│          │  参数列表 / 日志 / 子任务链接       │
└──────────┴──────────────────────────────────┘
```

## DAG 执行规则

- 使用 **Kahn 算法** 进行拓扑排序
- 无依赖的节点（入度为 0）可以并行执行
- 节点间通过**文件路径**传递数据（非二进制）
- 上游节点完成后，下游节点自动获取其输出文件路径
- 如果任一节点失败，工作流标记为失败，后续节点停止执行
- 内联节点（图像处理）在引擎进程内由 PIL 直接执行，不走子进程调度

## 监控与调试

- 运行中的工作流显示实时 DAG 视图，节点颜色表示状态：
  - 灰色 = 等待中
  - 蓝色 = 运行中
  - 绿色 = 已完成
  - 红色 = 失败
- 点击节点 Tab 可查看对应节点的输出文件和详情
- 点击图片可放大预览，点击 STL 可下载
- 支持取消运行中的工作流
- 支持 Replay 重放失败的工作流

## 最佳实践

1. **从小工作流开始** — 先测试 2-3 个节点的简单流程，再扩展到复杂 DAG
2. **使用模板** — 从预置模板开始，根据需求调整
3. **关注 GPU 节点** — GPU 节点串行执行，合理规划避免瓶颈
4. **添加 Repair 节点** — 在最终输出前添加修复节点确保打印质量
5. **用 Output 节点标记结果** — 明确标记哪些文件是工作流的最终输出
6. **利用图像处理节点** — 去背景、缩放等节点在引擎内执行，速度快且不占任务队列
7. **注意端口类型匹配** — image → image、mesh → mesh 类型一致才能连线
