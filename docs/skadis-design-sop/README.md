# 宜家／兼容洞洞板配件设计 SOP

**2026-09-28 更新：床头夹具默认改用 [V1.2 等宽轻量版](bedhead-v12-feedback.md)。**下面保留的14／20.4 mm厚度及M4×16配置属于V1.1历史基线；新床头设计优先读取参数库的 `preferred_profiles`。柜侧挂架V3.1参数保持独立。

版本：1.0 · 2026-09-27。适用于本工作区后续洞洞板挂钩、夹具、置物架、拼接件和收纳件设计。当前知识来自本地收藏模型、床头夹具 A V1.1 与柜侧挂架 V3.1 的几何和切片记录；不是宜家官方尺寸规范，也没有实物承重认证。

## 从哪里开始

1. 阅读本文的接口选择和流程，再打开 [可复用参数](parameters.json)。参数中的 `status`、`source` 和 `limitations` 必须一并阅读。
2. 在 [可搜索模型索引](reference-index/index.html) 按用途、文件名或对象名查找；[对象明细 CSV](reference-index/objects.csv) 用于快速定位网格；[完整 JSON](reference-index/catalog.json) 保存源文件哈希、成员路径、作者、许可原文字段和重复网格关系。
3. 阅读 [参考模型选用指南](reference-guide.md)，优先复用已核验的接口，不从预览图片估算关键尺寸。
4. 从 [组件清单](components/manifest.json) 选择粗螺杆、母螺口和接口试配件。复制到新设计目录后修改，保留原件及其来源。
5. 用 [新配件需求与验收模板](new-design-template.md) 记录新需求和试配结果；最后按本 SOP 交付。

## 一、把尺寸的含义写清楚

默认单位 mm。装配坐标采用：X 从家具前侧向后，Y 沿家具左右，Z 向上。打印摆放是另一套坐标，必须保存旋转和平移关系。不能直接拿 STL 的打印包络当装配尺寸。

| 名称 | 含义 | 例子 |
|---|---|---|
| 夹持范围 | 调整后可夹的目标板材厚度 | `夹20-40` = 20～40 mm |
| 主体宽度 | 沿家具左右方向的夹体宽度 | `宽44` = 44 mm |
| 接口头宽度 | 容纳固定孔距的局部宽度 | H4 至少54；S至少44 |
| 前臂厚度 | 前夹臂基础厚度 | 本次14 |
| 前座总厚度 | 含前臂在内的局部总厚度 | S款20.4，不是14再加20.4 |
| 顶臂长度／下垂高度 | 柜侧挂架的功能尺寸 | 不用于命名床头夹持范围 |

先记录目标家具板厚、顶面可用空间、板后至墙间隙、实际洞洞板型号及孔位、物品重量和重心距离。相同板厚不能代替接口兼容性检查。尚无荷载需求时，不能按宽度自动给出承重等级。

## 二、先选接口体系

### H4：四挂钩长孔接口

本次依据收藏 `桌边洞洞板夹具.3mf` 内的样例板网格测量：板厚约5、孔宽5.2、孔长15.2，同排及同列间距40。四钩采用40×40阵列，跳过中间错排孔。此数据是样例网格测量，不是每一块真实宜家板的实测保证。

当前钩宽4.4，样例孔每侧间隙约0.4；喉口5.8；钩尖横向R2.2，侧面轮廓R0.55。圆角需同时满足导入、喉口和根部连接，不能只对渲染外观倒圆。

验证完整动作：对齐四孔→套入→下落约7.2→承托。落座后直接外拉应受钩唇限制，抬起后应可取出。当前未设防上抬保险扣；这个选择仅来自本次用户要求，新配件按取放方向和用途重新决定。

### S：M4角孔／拼接接口

依据 MSkadis 与 ModelB 标准件：角孔距相邻边各12.5，两块板无额外拼缝时对应双孔中心距25，螺丝通孔直径4.4。它与 H4 的40 mm长孔网格不同，不可称为全部宜家原板通用接口。

普通M4六角螺母名义对边7、厚约3.2。床头 A V1.1 的螺母槽厚4.0、对边包络7.6，左右独立15°向内下倾通道；外扩口名义约4.8×9、导入段约2。槽两端分别通向对应螺孔，内端限位，中间实体隔开，原下进T口已取消。扩口值是设计截面参数，侧表面处受斜坡及布尔相交影响，并非每个边都恰为同一矩形尺寸。

柜侧 V3.1 使用另一个配置：槽厚4.0、对边7.5、下降约3、中心坡度约17.5°。不要混写成与床头同一接口版本。两者都未验证“靠重力自动滑入”；浅坡只是导向，摩擦和毛刺可能需要轻推。

安装可达性比只画出螺母腔更重要：必须有连续外部入口、拿取空间、对孔方式和拆卸路径。先装螺母，再靠近家具安装。未拧上螺丝前侧口不自锁，不能用封闭槽的假设来装配。

## 三、螺丝长度按完整尺寸链计算

本次S座：前面至盲孔底有效深度16；样例安装板厚5。螺丝长度按平底头底面到尾端计算。令 L 为螺丝长度，T 为板厚，W 为垫片等外部叠层厚度：

`进入夹座长度 = L − T − W`

`尾端净余量 = 16 − (L − T − W)`

本次螺母名义占据前座表面后3.2～6.4 mm范围。应核对能否穿过螺母全部有效厚度；“没顶底”不等于“足够啮合”。加垫片会减少进入长度，也会减少啮合。沉头下沉和不同板厚必须重新建模。

| 螺丝 | 板厚5、无垫片时进入长度 | 尾端余量 | 当前结论 |
|---|---:|---:|---|
| M4×12 | 7 | 9 | 几何可用，啮合余量较小，需实物核对 |
| M4×16 | 11 | 5 | 当前优先 |
| M4×18 | 13 | 3 | 几何可用 |
| M4×25 | 20 | −4 | 不可直接使用，先顶底 |

通孔Ø4.4提供的是直径余量，并不使任意长度可用。支持更长螺丝时，要同时调整避让深度、家具侧隔墙和前座厚度，不能直接打穿后壁让尖端顶家具。热熔螺母、厚防松螺母、法兰螺母不沿用普通六角槽。

## 四、家具夹紧结构的选择

床头板竖直，U形夹具跨过顶边，顶梁通过薄保护垫坐在板顶。挂点尽量靠上，以减少不必要的下垂；重心外伸距离仍需单独评估。不能只凭“挂点高”认定稳定或承重合格。

前部基础厚14，S座局部20.4。固定前臂＋后部粗螺杆直接顶紧，当前不设活动挡板，也取消防退机构。螺杆端部接触面积、家具表面压痕、垫片压缩和手轮可达性必须在实物试配中检查。

厚度分档20～40、35～55、50～70，主体宽36／44／60，两接口共18种。优先选择能覆盖实际板厚的较小开口，而不是一只很长的夹具覆盖全部范围。薄端、厚端都要检查有效螺纹啮合、手轮与后臂间隙和尾部占位。

当前各档后臂内侧X=`上限+3`；前保护垫表面X=1，有效开口分别42／57／72，给最大板厚留2 mm调节空间。保护垫前面及顶面各按1 mm计，实物厚度变化会改变尺寸链。

共用螺杆杆身35＋旋钮10＝45。即使缩短夹体顶梁，板背至手轮末端仍约45，还需手指空间。最薄端手轮与后臂约2.35 mm间隙；后臂厚10.65。不可宣称“小档即可贴墙无缝安装”。

## 五、复用组件时保留什么

| 元素 | 可复用内容 | 复用前检查 |
|---|---|---|
| 原粗螺杆＋配对母螺纹 | 实际网格牙型、旋钮轮廓、相位关系 | 不是标准M16；不可只凭约15.38外径重画 |
| H4接口 | 钩轮廓、40×40阵列、圆角及套入路径 | 实际板厚、孔宽、涂层和错排 |
| S双孔座 | 25孔距、Ø4.4孔、独立侧槽、尾端避让 | 接口版本、五金规格、板厚、侧向操作空间 |
| 试配件 | H4小样、M4侧槽小样、母螺口及正式螺杆 | 仅用于先试配，不是额外装配配件 |
| 横向插接板 | 中段6、舌厚4、每端插入约12、每侧间隙0.2 | 柜侧系列接口；非床头夹具的默认附件 |
| 打印工程 | 独立对象、中文分盘、材料与摆放方式 | 不把原作者打印参数当新结构强度保证 |

原螺杆来自 `桌边洞洞板夹具.3mf` 的 `3D/Objects/object_16.model`，配对母螺纹来自 `object_17.model`，样例板来自 `object_4.model`。作者字段Ms；许可原文保存在索引与组件清单中。保留复用出处，公开发布时按原来源许可处理，不将复用部分标为原创。

当前粗螺纹螺距约4。原杆40＋旋钮15＝55，通过截短根部及旋钮得到45，并未整体缩放螺纹。对旋转＋平移同步扫掠验证，不能拿任意角度两网格重叠就判断牙型不兼容。

STL是网格，不等于可编辑参数化CAD。小样可以作配合基准；修改用参数源程序或重新构造指定表面。不要整体缩放来调节公差，否则孔距、螺距和功能尺寸一起改变。

## 六、每次新设计的执行流程

1. **确认需求及坐标。**记录用途、家具方向、尺寸、装拆方向、可用墙缝、目标材料、打印机、物品重量与重心。区分用户已确认要求与本次假设。
2. **检索收藏库。**查索引和重复网格组；读取候选源3MF内部对象及变换。先定位可复用接口，再设计承载主体。文件名、缩略图和包络仅用于筛选。
3. **建立接口契约。**记录孔中心、板厚、喉口、螺母入口、螺丝尾部空间、保护层、定位面及版本。对来源测量标明来源；对自己设定的间隙标明“设计值”。
4. **构建最小试配件。**H4整组四钩、M4含侧口及孔底的小样、完整母螺纹和螺杆。公差紧／中／松变体仅改变指定配合面，明确变化量。
5. **参数化展开。**分别枚举夹厚、宽度、接口；共用零件只维护一份。更换头宽后重新计算侧入口长度，避免宽版通道到不了侧壁。
6. **验证装配路径。**从外部开始连续扫掠，检查螺母不会被困、挂钩能套入再落座、螺丝不顶底、粗螺纹相位正确、手轮不撞后臂。终态无碰撞不能替代装入路径验证。
7. **验证最终导出。**回读STL检查闭合、法向、实体数量和尺寸；再核验3MF实际对象与对应路径。记录变换、单位、对象ID和源文件哈希。XML坐标舍入后自动合并顶点可能改变拓扑；先检查原索引，再判断真实缺陷，不以“自动修复成功”代替分析。
8. **切片检查。**使用交付工程的实际方向及参数切片所有变体，检查缺壁、桥接、不可清理支撑、热床边界和对象间距。保存结果、警告、耗材与预计时间。
9. **实物验证。**先接口试配，再空载装配，随后按实际需求逐级载荷和持续夹紧观察。记录材料品牌、打印参数、方向、环境、载荷、时间、变形和损坏；未完成则明确“未实物验证”，不填额定承重。
10. **交付及回写。**更新参数、组件来源、验证状态、主工程、单盘、小样、说明和最新版指针。旧版留存，新版入口必须明确，避免用户打开旧V1误以为新特征没建出来。

## 七、打印基线与验证边界

当前床头工程：P1S／0.4喷嘴／PETG／0.20层高／6墙／主体50% Gyroid／螺杆100%，喷嘴255°C、热床70°C、最大体积速度8 mm³/s作为已保存配置；不是所有线材的最佳参数。主体侧放，粗螺杆旋钮底面朝下。

床头夹具启用普通自动支撑，并允许模型上起支撑；柜侧 V3.1 工程不启用支撑。两者不能互相覆盖设置。15°是使用姿态的导槽坡度，不是打印悬垂角，不能据此宣称无支撑可打印。

本次床头验证基线：22种STL、19盘；粗螺纹20 mm行程81个相位；H4套入下落73个位置，外拉有止挡；9种S款左右各81个路径位置，底T槽封闭、内端止挡；M4×12／16／18尾端避让；19盘实际切片无警告。没有实物摩擦、载荷及长期蠕变数据。

## 八、交付清单和版本规则

交付目录中应有：`最新版说明.md`、版本化主3MF、独立单盘3MF、单件STL、接口试配件、参数JSON、来源清单、验证JSON、装配图、中文说明、SHA256清单。主工程和对象名同时体现版本及尺寸，装配图必须从最终模型生成，至少包括整体、侧口近景和剖面；只给正面图无法说明隐藏螺母入口。

小版本改入口／公差仍要升级名称，例如床头A V1→V1.1。说明清楚旧文件是否覆盖。不得让“最新版链接”仍指向旧工程；发布后用最终目标目录文件再检查哈希和压缩包。

本 SOP 同步副本位于 `E:/3dprint/自己设计合集/实用组件/宜家洞洞板配件设计SOP`；本工作区的 `docs/skadis-design-sop` 为编辑源。更新后运行打包脚本同步，避免两份独立演进。
