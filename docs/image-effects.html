🎨 图片特效节点 / Image Effect Node

支持 17 种图片风格化特效，涵盖艺术模拟、复古故障、色彩处理、变形抽象 4 大类。 纯 PIL+numpy 实现，毫秒级处理，无需 GPU。

节点概述

属性值
节点 IDimage_effect
分类process
输入端口image (image) — 任意 PNG/JPEG 图片
输出端口image (image) — 特效处理后的 PNG 图片
执行方式inline (PIL + numpy，引擎进程内直接执行)
GPU不需要
处理耗时通常 < 1s（取决于输入分辨率）
节点颜色■ #e91e63（玫红 = 创意特效类）

快速开始

在工作流编辑器中，从左侧面板的 Process 分类下拖入 图片特效 Effect 节点，连接到任意图片输出端口即可。

# 典型工作流链路
file_input → image_effect → output_file

# 或与其他处理节点组合
file_input → image_effect → relief → repair → output_file

💡 提示

特效节点可以串联多个，实现风格叠加。例如：pixelate → sepia 产生复古像素风效果。 通过调节 strength 混合强度，可以在原图和特效之间取得平衡。

艺术模拟 7 种

模拟传统绘画媒介和艺术风格的视觉效果。

🖌️ 油画 Oil Paint

oil_paint

局部色彩平均 + 边缘增强 + 饱和度提升。模拟油画颜料的厚重感和笔触融合。

detail → 笔触半径 (1-15px)，值越大笔触越粗犷

🎨 水彩 Watercolor

watercolor

高斯柔化 + 色彩减淡 + 边缘加深。呈现水彩颜料的透明感和边界渗色效果。

detail → 渗色扩散半径，值越大边界越模糊

✏️ 铅笔素描 Pencil Sketch

pencil_sketch

灰度反转 + 高斯模糊 + Dodge 混合。经典铅笔素描算法，线条细腻有层次。

detail → 线条浓度，值越大线条越深越粗

📺 卡通 Cartoon

cartoon

中值平滑 + 色彩量化 + 边缘检测叠加。模拟赛璐珞动画的色块和描边效果。

detail → 色块级别 (2-20色)，值越小色块越少越扁平

🖋️ 水墨画 Ink Wash

ink_wash

灰度分层 + 多层阈值抖动 + 留白处理。模拟中国传统水墨的浓淡干湿层次。

detail → 墨色层次数，值越大层次越丰富

🌅 印象派 Impressionist

impressionist

多偏移彩色笔触叠加 + 色彩增强。模拟莫奈风格的短笔触和光影颤动。

detail → 笔触大小 (3-24px)，值越大笔触越粗放

🧪 炭笔画 Charcoal

charcoal

灰度反转 + 高对比度 + 噪点纹理。模拟炭笔的粗糙颗粒感和深黑线条。

detail → 颗粒粗糙度，值越大纹理越明显

复古故障 4 种

模拟老式媒介、早期数字图像和印刷工艺的视觉特征。

👾 像素风 Pixelate

pixelate

缩小 + 最近邻放大。经典像素艺术风格，模拟 8-bit/16-bit 游戏画面。

detail → 像素尺寸 (2-64px)，值越大马赛克越明显

📷 怀旧棕褐 Sepia

sepia

灰度 + 棕褐色调矩阵。模拟 19 世纪蛋白照片的温暖棕褐色调。

detail → 色调深度，值越大越偏暖

🔵 网目印刷 Halftone

halftone

灰度映射为可变大小圆点网格。模拟报纸和杂志的 CMYK 网目印刷效果。

detail → 网点大小 (2-22px)，值越大网点越粗

📽️ 胶片质感 Vintage Film

vintage_film

偏色 + 颗粒噪点 + 暗角。模拟 35mm 胶片照片的色调偏移和物理纹理。

detail → 颗粒强度，值越大噪点越明显

色彩处理 4 种

全局色彩映射和风格化调色板转换。

🏴 海报化 Posterize

posterize

色彩量化 + 通道色阶压缩。减少颜色数量产生平面海报风格。

detail → 色阶级别 (2-16)，值越小色彩越少

🎭 双色调 Duotone

duotone

灰度映射到双色渐变。根据 color_scheme 选择配色方案。

detail → 对比度偏移，改变色调过渡曲线的陡峭程度

🍬 马卡龙 Macaron

macaron

低对比度 + 粉彩色调偏移 + 柔光模糊。流行的柔和甜美色彩风格。

detail → 柔和强度，值越大色彩越浅越粉

💡 霓虹 Neon

neon

高饱和 + 边缘发光 + 暗色背景。模拟霓虹灯管的发光效果。

detail → 发光强度，值越大光晕越强

变形抽象 2 种

几何变换和结构重组效果。

🗿 浮雕 Emboss

emboss

Emboss 卷积核 + 对比度增强。产生浅浮雕般的立体凹凸效果。

detail → 浮雕深度，值越大凹凸越明显

🔮 万花筒 Kaleidoscope

kaleidoscope

扇形镜像拼接。将图像中心区域进行多次镜像反射形成对称图案。

detail → 分段数 (4-22)，值越大图案越复杂

参数说明

参数类型默认值说明
style choice pixelate 选择特效风格，共 17 个选项。
艺术 oil_paint, watercolor, pencil_sketch, cartoon, ink_wash, impressionist, charcoal
复古 pixelate, sepia, halftone, vintage_film
色彩 posterize, duotone, macaron, neon
变形 emboss, kaleidoscope
strength float 0.0–1.0 0.8 通用混合强度：特效图与原图的 blend 比例。
0.0 = 完全原图，1.0 = 完全特效。
推荐 0.6–0.9，保留原图细节同时呈现明显效果。
detail int 1–10 5 细节/强度级别。语义随风格变化：
pixelate → 像素大小；posterize → 色阶级别；oil_paint → 笔触半径；
impressionist → 笔触大小；halftone → 网点大小；kaleidoscope → 分段数
其余风格 → 效果处理强度（1=弱，10=强）
color_scheme choice warm 配色方案，仅对 duotone、macaron、sepia、vintage_film、neon 生效：
warm = 暖色调（棕/橙/米），cool = 冷色调（蓝/青/白）
vivid = 鲜艳明亮，muted = 柔和淡雅

文件命名约定

输出文件使用语义化命名，由配置文件 config/image_effect_naming.yaml 控制。 默认模式为 {base}_{effect}.png，部分效果包含额外参数。 

# 示例
photo.jpg → pixelate (detail=8)  → photo_pixel_p8.png
photo.jpg → oil_paint (strength=0.8) → photo_oilpaint.png
photo.jpg → duotone (color=cool)   → photo_duotone_cool.png
photo.jpg → macaron               → photo_macaron.png
photo.jpg → kaleidoscope (detail=7) → photo_kscope_s7.png
photo.jpg → posterize (detail=3)  → photo_poster_l3.png

配置文件结构

编辑 config/image_effect_naming.yaml 可以自定义每个效果的文件名后缀和命名模式。

# 默认模式
default_pattern: "{base}_{effect}"

# 各效果的后缀标记
suffixes:
  pixelate:       pixel
  oil_paint:      oilpaint
  impressionist:  impress
  ...

# 特定效果的命名模式覆盖
overrides:
  pixelate:  "{base}_{effect}_p{detail}"
  duotone:   "{base}_{effect}_{color}"

变量说明： {base} = 输入文件主名， {effect} = 后缀标记， {strength} = 混合强度， {detail} = 细节级别， {color} = 配色首字母。同名文件自动追加 _1, _2。

扩展开发 — 添加新特效

新增特效只需 3 步，无需修改现有代码：

Step 1: 创建 Effect 类

在 web/image_effects/ 下选择合适模块（或新建），继承 BaseEffect 并用 @register_effect 装饰：

from web.image_effects import register_effect
from web.image_effects.base import BaseEffect

@register_effect
class MyNewEffect(BaseEffect):
    name = "my_effect"
    label = "My Effect"
    label_zh = "我的特效"

    def apply(self, img, strength=0.8, detail=5, color_scheme="warm"):
        img = self.to_rgb(img)
        # ... 实现你的特效算法 ...
        return self.blend(img, result, strength)

Step 2: 注册到 node_types

在 web/node_types.py 的 image_effect 节点 style 参数的 choices 列表中添加你的效果名称。

Step 3: 配置命名后缀

在 config/image_effect_naming.yaml 中添加后缀映射（可选，默认使用效果名称）。

BaseEffect 接口

方法/属性说明
name: str效果唯一标识（snake_case）
label / label_zh双语显示名称
apply(img, strength, detail, color_scheme)核心方法，返回 PIL Image
blend(original, processed, strength)静态方法，按比例混合原图与效果
to_rgb(img, bg_color)静态方法，安全转换为 RGB 模式

架构设计

模块结构

web/image_effects/
├── __init__.py     注册中心 + 调度器 (get_effect, list_effects)
├── base.py         抽象基类 (BaseEffect)
├── naming.py       文件命名引擎（读取 YAML 配置）
├── artistic.py     艺术模拟 (7 个效果)
├── retro.py        复古故障 (4 个效果)
├── color.py        色彩处理 (4 个效果)
└── distortion.py   变形抽象 (2 个效果)

config/
└── image_effect_naming.yaml   文件名后缀配置

设计原则

  • 开闭原则：新增特效只需添加新类 + 装饰器，不改动现有代码
  • 单一职责：每个模块文件只包含同类效果，避免单文件过大
  • 配置驱动：文件名后缀集中管理，支持按效果自定义命名模式
  • 通用参数复用：4 个参数（style / strength / detail / color_scheme）覆盖全部 17 种效果
  • 零额外依赖：仅使用项目已有的 PIL + numpy
