AI 图像转 3D 打印指南

从一张参考图片到 Bambu 打印机可用的 STL 文件 — AI 3D 生成、浮雕建模、网格修复、六视图渲染、端到端流水线

🚀 一行命令上手

TripoSR 快速预览（约 30 秒）

python scripts/image-to-3d.py photo.jpg --format glb

Hunyuan3D-2.1 高精度（16GB: ~28min @25步）

python scripts/hunyuan-to-3d.py photo.jpg --steps 25 --resolution 256

🌐 Web 管理平台

项目提供了完整的 Web 管理界面，可通过浏览器提交任务、实时监控进度、管理输出文件、编辑工作流。 前端为模块化 ES modules SPA，支持中英文切换，暗色主题，响应式布局。

⚡ TripoSR — 快速预览引擎

Stability AI × Tripo AI 联合开源 (MIT)，单图 ~2 秒生成带顶点色的 3D 网格。

安装

# 1. 安装依赖
pip install torch torchvision # PyTorch (CUDA)
pip install trimesh rembg[gpu] pillow numpy huggingface_hub omegaconf

# 2. 下载模型权重 (1.6GB)
set HF_ENDPOINT=https://hf-mirror.com
python -c "from huggingface_hub import hf_hub_download; \
  hf_hub_download('stabilityai/TripoSR','model.ckpt',local_dir='models'); \
  hf_hub_download('stabilityai/TripoSR','config.yaml',local_dir='config')"

基本用法

# 生成 GLB (预览用, 带顶点色)
python scripts/image-to-3d.py photo.jpg

# 指定输出格式和精度
python scripts/image-to-3d.py photo.jpg \
    --format obj \
    --resolution 384

# 已有透明背景的图片跳过背景去除
python scripts/image-to-3d.py render.png --no-bg-remove

参数说明

参数默认说明
image必填输入图片路径 (jpg/png/webp)
--formatglb输出格式: glb (预览) / obj (通用)
--resolution256MC 分辨率: 128 (快) → 384 (精细)
--no-bg-remove关闭跳过 rembg 背景去除
--foreground-ratio0.85前景占比 (0.7–0.95)

常见错误

No onnxruntime backend found

rembg 需要 GPU 支持。修复：

pip install rembg[gpu]

ModuleNotFoundError: No module named 'torchmcubes'

torchmcubes 仅支持 Linux。项目已替换为 skimage 实现，无需额外操作。

背面/底面糊成一片

单视图输入的固有限制。试试多角度拍摄输入图片。

🏆 Hunyuan3D-2.1 — 高精度引擎

腾讯混元开源，两阶段架构：几何生成 (ShapeVAE + DiT Flow Matching) → PBR 纹理生成。
当前脚本为 geometry-only 模式（无纹理白模，可直接打印）。

安装

前提：ComfyUI 便携版已解压

整合包（百度/夸克网盘）解压到项目目录下，路径含中文不影响内嵌 Python 运行。
Hunyuan3D 脚本使用整合包自带的内嵌 Python（python_embeded/python.exe），
不需要额外安装依赖。

基本用法

# 快速预览 (16GB 卡约 11min)
python scripts/hunyuan-to-3d.py photo.jpg \
    --steps 10 \
    --resolution 128

# 高质量 (推荐, 约 28min)
python scripts/hunyuan-to-3d.py photo.jpg \
    --steps 25 \
    --resolution 256

# 指定输出格式
python scripts/hunyuan-to-3d.py photo.jpg \
    --format stl \
    --seed 123

# 图片已有透明背景
python scripts/hunyuan-to-3d.py render.png --skip-bg-remove

# 指定便携版路径
python scripts/hunyuan-to-3d.py photo.jpg \
    --base-dir "D:/projects/3dprint/混元3D2.1+..."

参数说明

参数默认说明
image必填输入图片路径
--steps15扩散步数: 5-10 预览 / 25-50 高质量
--resolution256MC 分辨率: 128 (快) → 384 (精细)
--formatglb输出格式: glb / obj / stl
--seed42随机种子 (可复现结果)
--modegeometrygeometry (白模) / full (纹理, 开发中)
--skip-bg-remove关闭跳过背景去除
--base-dir自动检测整合包根目录

常见错误

RuntimeError: CUDA out of memory

VRAM 不足。降低参数重试：

python scripts/hunyuan-to-3d.py photo.jpg --steps 5 --resolution 128

ModuleNotFoundError: No module named 'ComfyUI-Hunyuan3d-2-1'

目录名含连字符导致 Python import 失败。脚本已内置 monkey-patch 修复此问题。
如仍出现，检查 --base-dir 是否正确。

Inference tensors cannot be saved for backward

pipeline 的 @torch.inference_mode() 导致。脚本已通过 latents * 1.0 处理。

生成速度极慢 (287s/步)

RTX 3060 Laptop 热降频 (thermal throttling)。降低环境温度或使用散热底座。

🔧 Mesh Repair — 网格修复

将生成的网格修复为水密 (watertight) 可打印 STL：

  • 删除重复面 (unique_faces)
  • 删除退化三角面 (nondegenerate_faces)
  • pymeshfix 填洞 + 修复流形错误
  • 输出可直接切片打印的 STL
# 基本修复
python scripts/mesh-repair.py output/photo_3d.glb

# 缩放 + 指定输出
python scripts/mesh-repair.py model.glb \
    --scale 0.5 \
    --output stl

# 详细日志
python scripts/mesh-repair.py model.glb --verbose
参数默认说明
input必填输入网格 (.glb/.obj/.stl)
--outputstl输出格式: stl (打印) / 3mf / obj
--scale1.0统一缩放比例
--verbose关闭显示修复详情

📷 六视图渲染 — 模型验证

从任意 3D 网格渲染正交六视图（前/后/左/右/上/下），用于：

  • 验证 AI 生成模型的几何质量（无需打开 3D 查看器）
  • 生成模型卡片 / 文档配图
  • 为后续多视图重建提供输入
# 基本用法
python scripts/mesh-to-views.py model.glb

# 高分辨率 + 仅网格图
python scripts/mesh-to-views.py model.stl \
    --resolution 2048 \
    --no-individual

# 指定输出目录
python scripts/mesh-to-views.py model.obj \
    --output-dir D:/renders/
参数默认说明
mesh必填输入网格 (.glb/.obj/.stl)
--resolution1024单视图分辨率 (px)
--output-dir自动输出目录 (默认: <mesh_dir>/views/)
--no-grid关闭不生成合并网格图
--no-individual关闭不生成单独视图文件

输出文件

单个视图: {name}_front.png → {name}_bottom.png
合并网格: {name}_views_grid.png (3列×2行)
布局: front | right | back / left | top | bottom

🔄 Pipeline — 端到端流水线

一键完成：图片 → 3D 生成 → 网格修复 → 可打印 STL。
支持两个引擎，通过 --engine 切换。

# TripoSR 快速流水线 (默认, ~30s)
python scripts/pipeline.py photo.jpg \
    --resolution 256 \
    --scale 1.0

# Hunyuan3D-2.1 高精度流水线
python scripts/pipeline.py photo.jpg \
    --engine hunyuan \
    --steps 10 \
    --resolution 256

# 仅修复已有网格 (跳过生成)
python scripts/pipeline.py existing.glb --skip-generate

# 生成 + 修复 + 六视图验证
python scripts/pipeline.py photo.jpg --views

# 仅生成不修复
python scripts/pipeline.py photo.jpg --skip-repair
参数默认说明
image必填输入图片（或已有网格配合 --skip-generate）
--enginetriposr生成引擎: triposr (快速) / hunyuan (高精度)
--scale1.0统一缩放
--resolution256MC 分辨率
--no-bg-remove关闭跳过背景去除
--skip-generate关闭传入已有网格，仅修复
--skip-repair关闭仅生成，不修复
--views关闭生成六视图网格图
--steps15[Hunyuan] 扩散步数
--seed42[Hunyuan] 随机种子
--base-dir自动检测[Hunyuan] 整合包路径

模板流程适用场景

执行引擎

  • 拓扑排序：Kahn 算法自动解析节点执行顺序
  • 端口数据流：上游输出文件路径自动传递给下游输入端口
  • GPU 锁：asyncio.Lock 确保 GPU 节点串行执行
  • CPU 并发：Semaphore(3) 控制 CPU 节点并行度
  • 内联节点：图片处理节点在引擎进程内直接执行（PIL），无需启动子进程
  • Replay：支持从任意节点重放，保留上游已完成结果
  • SSE 实时推送：节点级进度事件（node_start/node_complete/node_error/node_progress）

🏔 浮雕生成 — 图像转浮雕

从图像直接生成3D可打印的浮雕，支持立体浮雕和透光浮雕（lithophane）两种模式，可选单色或四色打印。

普通浮雕（反射光）

# 标准浮雕 (160×120mm, 3mm 起伏)
python scripts/image-to-relief.py photo.jpg \
    --width 160 \
    --height 120

# 4色量化 + 顶点着色
python scripts/image-to-relief.py photo.jpg \
    --colors 4

透光浮雕（背光）

Light=薄=透光多, Dark=厚=透光少。使用厚度差在背光下呈现灰度图像。
推荐白色 PLA，100% 填充，平放打印即可。

# Lithophane 模式 (0.6mm 最薄, 2.6mm 最厚)
python scripts/image-to-relief.py photo.jpg --lithophane

# 自定义厚度范围
python scripts/image-to-relief.py photo.jpg \
    --lithophane \
    --base-thickness 0.8 \
    --max-depth 2.5
参数默认说明
image必填输入图片
--width160目标宽度 mm（等比缩放）
--height120目标高度 mm
--max-depth3.0/2.0起伏幅度 mm（lithophane 默认 2.0）
--base-thickness0.5/0.6底板厚度 mm（lithophane 默认 0.6）
--detail0.25细节保留强度 0-1
--lithophane关闭透光浮雕模式（亮区薄→透光）
--colors0颜色量化数 (0=单色, 2-4 多色)

两种模式对比

普通浮雕透光浮雕
厚度0.5 + 0~3 = 3.5mm0.6~2.6mm
原理亮=高（反射光）亮=薄（透射光）
观察方式正面光照背面 LED 灯板
推荐耗材任意 PLA白色/象牙白 PLA
打印方向平放平放（背面朝下）
填充15-20%100% 实心

分层彩层浮雕（多色 AMS）

专用多色打印脚本，按亮度分层生成彩色浮雕。可选四种颜色，Z 高度边界自动配置换丝事件，3MF 直连 Bambu Studio。

# 4色分层浮雕 → 完整 3MF（Bambu AMS 多色打印）
python scripts/image-to-layered-relief.py photo.jpg \
    --width 160 \
    --height 120 \
    --colors 4 \
    --format 3mf \
    --printer P1S \
    --multi-color-mode auto
参数默认说明
image必填输入图片
--width160目标宽度 mm
--height120目标高度 mm
--colors4颜色数量 (2-16)
--layer-height0.4每层高度 mm
--base-thickness0.3底板厚度 mm
--printerP1S打印机: P1S / A1
--formatstl输出格式: stl / 3mf

⚠ 避坑指南

1. 输入图片质量最重要

主体突出、背景干净、光照均匀的图片效果远好于杂乱背景。
如果图片背景复杂，rembg 可能误删主体的一部分。

2. 单视图输入的固有限制

单张照片只能看到物体的一面。背面、底面、遮挡区域的几何质量会明显下降。
Hunyuan3D-2.1 比 TripoSR 更能推测背面形状，但仍有局限。

3. 16GB 显存可同时运行浏览器

RTX 5070 Ti 16GB 绰绰有余，Hunyuan3D-2.1 占 ~7GB。
浏览器等应用不会影响推理速度。

4. 首次运行建议低参数验证

首次运行建议 --steps 5 --resolution 128 验证流程。
确认无误后再跑 --steps 25 高质量模式。

5. STL 打印前必须修复

AI 生成的原始网格通常不是水密的（有小洞、非流形边、重复面）。
mesh-repair.py 会修复这些问题并验证水密性。

6. 编码问题 (Windows)

中文路径和 UTF-8 打印偶尔出问题：

set PYTHONIOENCODING=utf-8     # PowerShell
$env:PYTHONIOENCODING="utf-8"  # CMD

7. HF 镜像 (国内下载加速)

set HF_ENDPOINT=https://hf-mirror.com
