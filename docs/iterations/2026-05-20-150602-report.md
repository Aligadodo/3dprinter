## 六、关键架构决策

1. **端口类型兼容规则**：独立规则引擎放在 `dag.py`（纯函数层），在 workflow engine 执行前调用。支持同类型、wildcard（* / any）、file→image/stl/mesh、string→image、stl↔mesh、json→string/json、dir→any。

2. **Provider 联动**：前端文本生图面板改为延迟加载 + 动态渲染，首次展开时才从 `/api/text2img/providers` 获取列表，切换 provider 时尺寸自动联动。

3. **参数定义同步**：schemas.py（backend 校验）和 node_types.py（前端节点表单）之间通过测试 (`test_schema_consistency.py`) 保证关键参数一致性。
