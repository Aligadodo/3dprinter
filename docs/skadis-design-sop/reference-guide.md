## 3MF读取原则

3MF是ZIP工程包。`3D/3dmodel.model`可能只引用外部对象，实际网格在`3D/Objects/*.model`。必须同时记录成员路径和object ID，不能仅用object ID跨文件查找。`Metadata/model_settings.config`可包含对象名、零件角色、材料及分盘设置；非normal_part不能直接当实体打印件。

网格的局部坐标、component变换、build实例变换、打印盘位置不是一回事。索引只报告**网格局部包络**，未将组件或排盘变换应用到包络。变换后的孔位需要在统一装配坐标测量，不能把几个包络尺寸相加来当总装尺寸。

随附 `scripts/extract_3mf_component.py` 只提取指定网格并转为mm，故意不把整个工程合并。它会生成 `.source.json` 记录源哈希、成员、ID和坐标说明。若要提取完整组件，请另行解析组件链并应用3MF变换；不要拿该脚本当通用总装导出器。

示例（在本SOP目录运行，保持PowerShell路径引号）：

```powershell
python scripts/extract_3mf_component.py 'E:/3dprint/模型收藏合集/宜家洞洞板系列收藏/桌边洞洞板夹具.3mf' '3D/Objects/object_16.model' 1 'scratch/source-screw.stl'
```

原模型作者、描述与许可字段只是来源数据。缺失字段按“未记录”处理，不推断可自由商用；预览图不代表已经验证的尺寸与效果。

## 如何刷新

在工作区根目录运行：

```powershell
python scripts/index_skadis_library.py
python scripts/build_skadis_knowledge.py
python scripts/package_skadis_sop.py
```

索引器只读取收藏目录，在SOP目录写输出。第一次更新后检查错误列表、新增模型与角色；按需要补充本指南和参数配置，再同步到E盘。脚本不安装软件，不访问网络。依赖Python、NumPy、trimesh、Pillow；几何构建源另需manifold3d和Shapely。
