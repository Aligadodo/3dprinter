# 参数级联传递 + 端口/参数分离

## 问题

- 端口和参数定义混淆（`text_to_image` 的 `size`/`provider` 定义为 port 而非 param）
- 未连线端口统一显示 "⚠ 未连接上游节点"，用户无法手动配置
- 上游节点的输入/输出/参数无法被下游节点引用
- 上下文不级联传递，每个节点孤立执行

## 设计

### 端口 vs 参数 分离

- **Ports**：数据流连线，传递文件/文本等产物
- **Params**：节点配置项，运行时可从上游选取或手动输入

### 级联传递

每个节点执行后，`ctx[nid]` 存储：
- 直接输出（当前已有）
- `_inputs`：本节点输入值
- `_params`：本节点使用的参数
- `_upstream`：全部上游节点上下文的合并视图

### UI 三态

- 📥 连线端口：绿色来源标签，只读
- ⚙ 可配参数（有上游匹配）：下拉选择 + 可切换自定义输入
- ⚙ 可配参数（无上游）：直接输入控件

## 实施步骤

1. 清理 text_to_image 节点定义（size/provider 从 port 移入 param）
2. 引擎级联：`_enrich_ctx()` 在节点执行后写入完整上下文
3. UI 重写：`showRunParamsDialog` 参数行三态渲染
