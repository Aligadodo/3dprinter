# 3D Print Pipeline — 工作流节点扩展 + 结果展示升级

## Context

当前工作流系统已跑通 text_input → text_to_image → relief 的端到端链路。但存在两个核心体验缺口：

1. **工作流运行结果展示不完善**：Runner 页面仅显示 DAG 状态图，节点输出以 9px 小字标注在 Canvas 上。没有集中的文件产物展示、没有图片预览、没有 STL 预览、没有"下载全部"功能。用户需要双击节点跳转到独立任务页才能看到输出文件。
2. **处理节点粒度太粗**：从 AI 生图到 3D 模型之间缺少必要的图像预处理环节（裁切、缩放、灰度化、对比度调节等），以及 3D 生成后的网格后处理环节（简化、平滑、缩放）。影响了工作流的实用性和灵活性。

## 设计目标

1. **工作流结果面板**：Runner 页面增加结构化的结果展示区（每节点输入/输出文件、参数、耗时）
2. **图像预处理节点**：裁切、缩放、灰度化、对比度调节、格式转换
3. **网格后处理节点**：简化(decimate)、平滑(smooth)、缩放(scale)
4. **背景移除节点**：AI 去背景（提升 3D 生成质量）
5. **引擎支持内联节点**：纯 Python 处理的节点不经过 scheduler 子进程，直接在引擎中同步执行

### 2.2 节点详细设计

#### `image_resize` (P0)
```
Label: 图像缩放 / Image Resize
Inputs:  image (image, required)
Outputs: image (image, required)
Params:
  - width:  int, default=512, min=64, max=4096  目标宽度(px)
  - height: int, default=512, min=64, max=4096  目标高度(px)
  - fit:    choice, default="cover"              缩放模式
            choices: ["cover"(居中裁切), "contain"(留白填充), "stretch"(拉伸), "scale_width"(按宽缩放), "scale_height"(按高缩放)]
  - filter: choice, default="lanczos"            重采样算法
            choices: ["lanczos", "bilinear", "bicubic", "nearest"]
```
**实现**: PIL `Image.resize()` + `ImageOps.fit()` / `ImageOps.contain()` / `Image.thumbnail()`

#### `image_grayscale` (P0)
```
Label: 灰度转换 / Grayscale
Inputs:  image (image, required)
Outputs: image (image, required)
Params:
```

## 三、引擎架构调整：支持内联节点

### 3.1 当前问题

所有 process 节点通过 `node_pipeline_map()` 映射到 pipeline type，执行时走 `_run_pipeline()` → scheduler 子进程。但图像处理节点（resize/crop/grayscale 等）是纯 PIL 操作，不需要子进程。

### 3.2 解决方案

在 `NodeType` 中增加 `inline_handler` 字段：

```python
# node_types.py
class NodeType:
    def __init__(self, ...):
        ...
        self.inline = False          # True = 引擎直接执行, 不走 scheduler
        self.inline_handler = None   # async callable(nid, node, node_params, ctx, instance_id, node_run_id)
```

在 `workflow_engine._execute()` 中：
```python
nt = node_types.get_node_type(node["type"])
if nt and nt.inline and nt.inline_handler:
    await nt.inline_handler(nid, node, node_params, ctx, instance_id, node_run_id)
else:
    # 现有 pipeline 调度逻辑
```

### 3.3 内联节点实现位置

创建 `web/inline_nodes.py`，包含所有内联节点的处理函数：
```python
# inline_nodes.py
from PIL import Image, ImageEnhance, ImageOps
import os

async def run_image_resize(nid, node, node_params, ctx, instance_id, node_run_id):
    """PIL-based image resize."""
    ...

async def run_image_grayscale(nid, node, node_params, ctx, instance_id, node_run_id):
    """PIL-based grayscale conversion."""
    ...

async def run_image_crop(nid, node, node_params, ctx, instance_id, node_run_id):
    """PIL-based image crop."""
    ...

async def run_image_adjust(nid, node, node_params, ctx, instance_id, node_run_id):
    """PIL-based brightness/contrast/saturation/sharpness adjustment."""
    ...

async def run_image_convert(nid, node, node_params, ctx, instance_id, node_run_id):
    """PIL-based format conversion."""
    ...

async def run_remove_background(nid, node, node_params, ctx, instance_id, node_run_id):
    """rembg-based background removal."""
    ...

# Registry
INLINE_HANDLERS = {
    "image_resize": run_image_resize,
    "image_grayscale": run_image_grayscale,
    "image_crop": run_image_crop,
    "image_adjust": run_image_adjust,
    "image_convert": run_image_convert,
    "remove_background": run_remove_background,
}
```
