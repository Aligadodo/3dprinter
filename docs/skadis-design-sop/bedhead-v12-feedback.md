# 2026-09-28：床头等宽轻量版 V1.2

优先用于后续轻负载床头配件的起点，旧V1.1保留为历史来源，不再默认其加宽前头及M4×16配置。

## 实物反馈与边界

用户提供 `IMG_20260928_095853.jpg`：旧款可见明显悬空线条与表面缺陷，用户明确反馈宽度台阶增加打印难度、整体过厚。照片不包含切片设置、层预览和材料状态，不能把全部缺陷归因于一个原因，也不能认为原款已通过载荷验证。

可确认的结构问题：旧S款36 mm主体搭配44 mm前头，侧放时主体底面被抬高4 mm；旧H4最窄主体36、头54，则抬高9 mm。为了少量主体材料而增加这类大面积悬空不可作为默认优化方向。应先确认整件打印基准面，再做减重。

## 新默认值

- 前臂／顶梁9.4，S前座总厚13.6；较旧版分别减少约33%。后部母螺纹座9.4，保留原牙型，不机械地把每个部位都减薄三分之一。
- S主体／前头统一宽36、40、44；H4统一宽48、50、54。三档夹持范围仍为20–40、35–55、50–70。
- S中心孔距25、孔径4.4、中心Z=−1不变；H4孔位40×40不变。减薄仅改变前后板背距离，不整体缩放模型。
- S只按M4×12、板厚5、无垫片、普通M4螺母设计。盲孔深9、后壁4.6、尾端余量2；螺母名义深度2.8～6.0，最大偏移远面6.4，最少穿出0.6。
- 左右15°侧槽保留；槽厚4.0、对边包络7.6；前皮名义2.4、扩口处最薄约2.0。粗螺杆45 mm保持。
- 主体4墙、30% Gyroid，粗螺杆100%；自动支撑仍开。等宽减少主体悬空，不等于挂钩和内孔全部无需支撑。

## 注意连接系统的联动

S前座变薄后，旧20.4 mm背部支撑块不能直接混用；新座是13.6。顶梁变薄但挂钩高度不变，钩尖会高出顶梁约4.6。必须把这些影响告诉用户，不能只说“孔位没动所以一切兼容”。

全部18种主体最终STL和3MF核验通过，19盘实际切片无警告。按旧新宽度档对应，主体几何体积减少21.2%～50.7%；切片整盘耗材减少32.1%～53.2%，其中包含尺寸、支撑和填充变化，不能解释为纯粹厚度变化。V1.2尚无实物装配／载荷／长期蠕变验证。
