# 流水线类型参考

## 概述

系统支持 **10 种流水线类型**，每种类型有不同的输入要求、参数和输出。本页详细列出所有类型的完整说明。

---

## 1. 浮雕 (Relief)

**脚本**: `image-to-relief.py` | **类型**: CPU | **输入**: 图片 (.jpg/.png/.webp/.bmp)

将图片转换为 3D 浮雕，从正面观赏，通过反射光呈现凹凸效果。支持 4 色 AMS 多色打印。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| width | float | 160.0 | 20–500 | 目标物理宽度 (mm) |
| height | float | 120.0 | 20–500 | 目标物理高度 (mm) |
| max_depth | float | 3.0 | 0.5–10.0 | 浮雕最大深度 (mm) |
| base_thickness | float | 0.5 | 0.2–5.0 | 底板最小厚度 (mm) |
| detail | float | 0.25 | 0.0–1.0 | 细节保留程度（0=平滑，1=全部保留） |
| colors | int | 0 | 0–4 | 量化颜色数（0=单色） |
| pixel_spacing | float | 0.08 | 0.05–0.5 | 高度场分辨率 |

### 输出

- STL 网格文件
- 颜色预览图（PNG，如果颜色数 > 0）

---

## 2. 夜灯 (Lithophane)

**脚本**: `image-to-relief.py` | **类型**: CPU | **输入**: 图片

将图片转换为背光夜灯 — 薄处透光、厚处遮光。适合相框、灯罩等透光装饰品。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| width | float | 160.0 | 20–500 | 目标宽度 (mm) |
| height | float | 120.0 | 20–500 | 目标高度 (mm) |
| max_depth | float | 2.0 | 0.5–5.0 | 厚度变化范围 (mm) |
| base_thickness | float | 0.6 | 0.3–3.0 | 最薄处厚度 (mm) |
| detail | float | 0.15 | 0.0–1.0 | 细节保留程度 |
| colors | int | 0 | 0–4 | 量化颜色数 |

### 输出

- STL 网格文件

---

## 3. 多层套色浮雕 (Layered Color Relief)

**脚本**: `image-to-layered-relief.py` | **类型**: CPU | **输入**: 图片

单 mesh 高度分色浮雕 — 不同 Z 高度区间对应不同耗材颜色，配合 AMS / 多材料系统自动换色打印。输出 STL + 换色高度说明 + 可选 3MF。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| width | float | 160.0 | 20–500 | 目标宽度 (mm) |
| height | float | 120.0 | 20–500 | 目标高度 (mm) |
| colors | int | 4 | 2–16 | 耗材颜色数量 |
| layer_height | float | 0.4 | 0.2–1.0 | 每种颜色的 Z 高度区间 (mm) |
| base_thickness | float | 0.3 | 0.2–1.0 | 底板最小厚度 (mm) |
| edge_smooth | float | 0.5 | 0.0–1.0 | 颜色边界抗锯齿（0=锐利，1=柔和） |
| pixel_spacing | float | 0.08 | 0.05–0.5 | 高度场分辨率 |
| format | choice | stl | stl/3mf | 输出格式 |

### 输出

- STL 网格文件
- 换色说明 JSON（包含颜色、Z 高度区间、面积占比）
- 可选：Bambu Studio 兼容 3MF 文件
- 颜色预览图

## 4. TripoSR（快速 3D）

**脚本**: `image-to-3d.py` | **类型**: GPU | **输入**: 图片

快速 AI 图片转 3D 网格，约 2 秒推理，输出带顶点色的 GLB。适合快速预览和原型验证。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| format | choice | glb | glb/obj | 输出格式 |
| resolution | int | 256 | 64–384 | Marching cubes 网格分辨率 |
| foreground_ratio | float | 0.85 | 0.7–0.95 | 背景移除裁剪比例 |
| no_bg_remove | bool | false | — | 跳过背景移除 |

### 输出

- GLB/OBJ 网格文件
- 渲染预览图

---

## 5. Hunyuan3D-2.1（高质量）

**脚本**: `hunyuan-to-3d.py` | **类型**: GPU | **输入**: 图片

高质量 AI 图片转 3D 网格，10-60 分钟，几何模式。适合最终模型输出。需约 7GB 显存。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| mode | choice | geometry | geometry/full | 模式（geometry=仅几何，full=含纹理） |
| steps | int | 15 | 5–50 | 扩散步数（10-15 预览，25-50 高质量） |
| resolution | int | 256 | 128–384 | Marching cubes 分辨率 |
| seed | int | 42 | 0–2147483647 | 随机种子 |
| format | choice | glb | glb/obj/stl | 输出格式 |
| skip_bg_remove | bool | false | — | 跳过背景移除 |

### 输出

- GLB/OBJ/STL 网格文件
- 渲染预览图

---

## 6. 网格简化 (Mesh Simplify)

**脚本**: `mesh-simplify.py` | **类型**: CPU | **输入**: 3D 网格 (.glb/.obj/.stl/.gltf)

通过二次误差度量减面，降低面数同时保持模型外观。适合降低打印文件大小和切片速度。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| target_faces | int | 50000 | 1000–1000000 | 目标三角面数量 |
| method | choice | quadric | quadric/cluster | 算法（quadric=保形质量好，cluster=速度快） |

### 输出

- 简化后的网格文件（同输入格式）

---

## 7. 网格平滑 (Mesh Smooth)

**脚本**: `mesh-smooth.py` | **类型**: CPU | **输入**: 3D 网格 (.glb/.obj/.stl/.gltf)

使用 Taubin 算法平滑网格表面，去除噪点同时避免体积收缩。适合改善 AI 生成模型的不规则表面。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| iterations | int | 3 | 1–20 | 平滑迭代遍数（越多越光滑，越慢） |
| lambda | float | 0.5 | 0.0–1.0 | Taubin 平滑强度（越大越平滑） |
| mu | float | -0.53 | -1.0–0.0 | Taubin 反收缩系数（负值防止体积缩小） |

### 输出

- 平滑后的网格文件

---

## 8. 网格缩放 (Mesh Scale)

**脚本**: `mesh-scale.py` | **类型**: CPU | **输入**: 3D 网格 (.glb/.obj/.stl/.gltf)

按比例或目标尺寸缩放网格。适合调整模型到打印平台可容纳的尺寸。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| scale | float | 1.0 | 0.01–100.0 | 均匀缩放倍数（1.0=不变，2.0=放大两倍） |
| target_width | float | 0.0 | 0.0–1000.0 | 目标物理宽度 mm（0=使用缩放倍数） |
| uniform | bool | true | — | 三轴等比缩放（保持比例） |

### 输出

- 缩放后的网格文件

---

## 9. 六视图 (Views)

**脚本**: `mesh-to-views.py` | **类型**: CPU | **输入**: 3D 网格 (.glb/.obj/.stl/.gltf)

从已有 3D 网格渲染六面正交视图（前/后/左/右/上/下），输出 PNG 图片。适合文档和模型验证。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| resolution | int | 1024 | 256–4096 | 每张视图的输出分辨率 |
| no_grid | bool | false | — | 仅生成单独视图，跳过 3×2 组合图 |

### 输出

- 六张独立视图 PNG
- 3×2 组合图 PNG
- views 目录

---

## 10. 网格修复 (Repair)

**脚本**: `mesh-repair.py` | **类型**: CPU | **输入**: 3D 网格 (.glb/.obj/.stl/.gltf)

修复并封闭网格，输出 3D 打印就绪的 STL。包含去重、填洞、非退化检查和减面。

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| output_format | choice | stl | stl/obj/3mf | 输出格式 |
| scale | float | 1.0 | 0.1–10.0 | 均匀缩放倍数 |

### 输出

- 修复后的网格文件
