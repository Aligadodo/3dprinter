# Local design references

For tasks about 宜家 / SKÅDIS / MSkadis pegboards, clamps, mounting hardware, or compatible accessories, first read `docs/skadis-design-sop/README.md`, then the relevant profiles in `docs/skadis-design-sop/parameters.json` and `reference-guide.md`.

Use `docs/skadis-design-sop/reference-index/catalog.json` to locate source 3MF components and `components/manifest.json` for extracted reusable parts. These are local reference measurements and prototype defaults, not universal IKEA specifications or tested load ratings. Preserve source provenance and keep H4 long-slot and ModelB M4 corner-hole interfaces distinct. Update the SOP when new physical measurements or validated revisions supersede a profile. This instruction applies only to pegboard accessory work; it does not change unrelated application-development workflows.
